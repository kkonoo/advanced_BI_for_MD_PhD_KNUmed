R Environment Setup

Principles of a Reproducible Workflow

Three things that will save you later:

  1. Project-based working — never setwd() again
  2. Consistent directory structure — know where everything lives
  3. Locked package versions — your code runs the same in 2 years

R Project Structure

my_project/
├── my_project.Rproj       # always open via this
├── renv.lock              # package versions locked here
├── data/
│   ├── raw/               # never modify these
│   └── processed/
├── R/
│   ├── 01_qc.R
│   └── 02_analysis.R
├── results/
│   ├── figures/
│   └── tables/
└── docs/                  # reports, QMD files

The here Package — No More Path Pain

library(here)

# Instead of:
read.csv("C:/Users/me/Desktop/project/data/raw/counts.csv")

# Use:
read.csv(here("data", "raw", "counts.csv"))

Works identically on Windows, Mac, and Linux.
Works regardless of where your Rproj file is.

Reproducible Environments with renv

# 1. Initialize — run once when starting a project
renv::init()

# 2. Install packages as usual
install.packages("Seurat")
BiocManager::install("DESeq2")

# 3. Snapshot — lock your current package versions
renv::snapshot()

# 4. Restore — on a new machine or for a collaborator
renv::restore()

Why this matters

Without renv, a Seurat update 6 months from now may silently break your code.

Hands-On

Let’s Set Up Together

Step 1 — Create a new R Project

File → New Project → New Directory → New Project
Name: "bioinformatics_2025"

Step 2 — Create directory structure

dirs <- c("data/raw", "data/processed", "R", "results/figures", 
          "results/tables", "docs")
sapply(dirs, dir.create, recursive = TRUE, showWarnings = FALSE)

Step 3 — Initialize renv

install.packages("renv")
renv::init()

Install Core Packages for This Semester

# CRAN packages
install.packages(c("here", "tidyverse", "BiocManager", 
                   "ggplot2", "patchwork", "data.table"))

# Bioconductor
BiocManager::install(c("DESeq2", "minfi", "phyloseq", 
                       "SingleR", "celldex"))

# Snapshot your environment
renv::snapshot()

Note

Some packages (Seurat, ArchR) we’ll install in the relevant week.
Bioconductor installs can take a few minutes — this is normal.

Verify Your Setup

# Run this — everything should load without errors
library(here)
library(tidyverse)
library(BiocManager)

sessionInfo()

If you hit errors → paste the error message in our class channel.
Common fix: BiocManager::install(version = "3.19")
